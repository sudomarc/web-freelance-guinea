# Templates

Templates réutilisables pour accélérer la production sans sacrifier la qualité.

## Principes

- mobile-first ;
- structure simple ;
- contenu facilement remplaçable ;
- aucune donnée fictive oubliée lors de la livraison ;
- composants simples et maîtrisés.

## Templates prévus

- `landing-page` ;
- `mini-site`.
