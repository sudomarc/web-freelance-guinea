# Restaurant Template

Template HTML/CSS réutilisable pour les mini-sites de restaurants, cafés et fast-foods.

## Objectif

Fournir une base rapide à personnaliser pour un client réel :

- nom et identité du restaurant ;
- menu ;
- horaires ;
- adresse ;
- WhatsApp ;
- Google Maps ;
- textes et photos.

## Personnalisation

1. Remplacer les contenus de démonstration dans `index.html`.
2. Remplacer le numéro WhatsApp.
3. Remplacer l'adresse et le lien Google Maps.
4. Ajouter les vraies photos du client.
5. Adapter les couleurs dans `style.css`.
6. Tester sur mobile avant livraison.

## Statut

Projet de démonstration. Le nom, les prix, l'adresse et les coordonnées sont fictifs et doivent être remplacés avant toute utilisation commerciale.
