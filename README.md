# Web Freelance Guinea

Micro-business de création de mini-sites et landing pages pour petites entreprises, indépendants, commerces et prestataires en Guinée.

## Objectif

Construire progressivement une activité freelance flexible, compatible avec les études, avec une offre volontairement simple :

- landing pages orientées conversion et contact WhatsApp ;
- mini-sites vitrines simples ;
- maintenance légère ;
- production rapide à partir de templates réutilisables.

## Positionnement

> Des pages web simples, professionnelles et adaptées au mobile pour aider les petites activités à présenter leurs services et faciliter le contact.

Le projet ne cherche pas à devenir immédiatement une agence web généraliste. Les projets complexes (e-commerce, applications, systèmes de paiement personnalisés, plateformes, infrastructure avancée) sont volontairement hors périmètre initial.

## Stack initiale

- HTML / CSS / JavaScript pour l'apprentissage et les projets statiques ;
- Carrd pour certaines landing pages commerciales lorsque cela réduit le temps de production ;
- GitHub pour le code, la documentation et le versionnement ;
- GitHub Pages lorsque l'hébergement statique est adapté ;
- WhatsApp comme canal commercial et point de conversion ;
- Google Drive / Sheets pour les contenus et le suivi commercial.

## Règles de travail

1. Ne jamais vendre une compétence qui n'est pas maîtrisée.
2. Définir le périmètre avant de commencer.
3. Demander un acompte avant la production.
4. Limiter explicitement les révisions incluses.
5. Séparer les coûts récurrents (domaine, hébergement, maintenance) du prix de création.
6. Refuser les projets dont le niveau technique dépasse les compétences disponibles.
7. Construire des templates réutilisables afin de réduire le temps de production.
8. Documenter les décisions importantes dans `docs/`.

## Statut

**Phase : validation et construction du portfolio.**

Le premier objectif est d'obtenir les premiers clients payants, mesurer le temps réel de production et ajuster l'offre avant toute expansion.
