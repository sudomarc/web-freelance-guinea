# Acquisition et vente

## Prospect idéal

Activité locale avec :

- Instagram ou Facebook actif ;
- WhatsApp ;
- activité commerciale réelle ;
- absence de site ou présence web insuffisante ;
- besoin simple et visible.

## Canaux

- Instagram ;
- Facebook ;
- Google Maps ;
- réseau personnel ;
- recommandations ;
- groupes professionnels pertinents.

## Routine initiale

10 prospects qualifiés par jour, avec messages personnalisés plutôt qu'un envoi massif identique.

## Angle commercial

Ne pas vendre « du HTML/CSS ». Vendre le résultat : une page centrale où le prospect peut comprendre l'activité et passer rapidement à l'action.

## Exemple de CTA

> J'ai préparé une petite démo adaptée à votre activité. Je peux vous l'envoyer ici.

## Refus

Ne pas argumenter inutilement. Comprendre l'objection, réduire éventuellement le périmètre si le problème est le budget, puis laisser une possibilité de revenir plus tard.

## Recommandations

Après une livraison réussie :

> Si vous connaissez une autre activité qui pourrait avoir besoin d'une page similaire, vous pouvez me mettre en contact avec elle.

## Suivi

Chaque prospect doit avoir un statut clair :

`À contacter → Contacté → Réponse → Discussion → Démo → Devis → Gagné / Perdu → Relance`
