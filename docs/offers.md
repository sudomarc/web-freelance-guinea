# Offres

## 1. Landing Page

### Positionnement

Une page web unique destinée à présenter une activité et à générer une action claire : message WhatsApp, appel, demande de devis, visite ou inscription.

### Inclus

- design mobile-first ;
- présentation de l'activité ;
- services ou offre ;
- galerie simple ;
- bouton WhatsApp ;
- téléphone et réseaux sociaux ;
- localisation / Google Maps ;
- formulaire simple si le besoin reste maîtrisé ;
- mise en ligne ;
- 2 séries de corrections.

### Hors forfait

- rédaction complète de contenu ;
- création avancée de logo ;
- fonctionnalités personnalisées complexes ;
- maintenance illimitée.

## 2. Mini-site vitrine

3 à 5 pages maximum :

- Accueil ;
- À propos ;
- Services ;
- Galerie / réalisations ;
- Contact.

### Inclus

- responsive ;
- WhatsApp ;
- réseaux sociaux ;
- localisation ;
- formulaire simple ;
- SEO de base ;
- mise en ligne ;
- 2 séries de corrections.

## Options

- page supplémentaire ;
- rédaction / optimisation de contenu ;
- galerie avancée ;
- maintenance légère ;
- mises à jour de contenu ;
- configuration de domaine et hébergement.

## Refus initial

Tout projet dont les exigences dépassent les compétences réellement disponibles doit être refusé ou orienté vers un prestataire adapté.
