# Workflow de production

## 1. Prospect

Identifier une activité qui possède déjà une présence sociale mais pas de site ou de page centrale claire.

## 2. Qualification

Vérifier :

- activité réelle ;
- besoin identifiable ;
- objectif de la page ;
- contenu disponible ;
- budget compatible ;
- complexité technique.

## 3. Brief

Collecter identité, coordonnées, services, horaires, localisation, photos, logo, textes, liens sociaux et objectif principal.

## 4. Devis

Définir : périmètre, prix, délai, nombre de révisions, coûts externes, paiement et conditions de livraison.

## 5. Acompte

Recevoir 50 % avant de commencer la production.

## 6. Contenu

Ne pas commencer la production finale tant que les contenus indispensables ne sont pas disponibles ou clairement validés.

## 7. Design

Construire d'abord la structure mobile et la hiérarchie des informations.

## 8. Développement

Utiliser un template maîtrisé plutôt que repartir de zéro.

## 9. Contrôle qualité

Vérifier au minimum :

- mobile ;
- desktop ;
- liens ;
- WhatsApp ;
- téléphone ;
- formulaire ;
- images ;
- orthographe ;
- navigation ;
- titre et description ;
- vitesse raisonnable ;
- absence d'informations de démonstration laissées par erreur.

## 10. Corrections

Traiter les deux séries de corrections incluses dans le devis.

## 11. Solde

Recevoir le solde avant la livraison finale / publication définitive lorsque le projet le justifie.

## 12. Livraison

Fournir au client les accès et informations nécessaires, documenter le domaine et l'hébergement et conserver une copie du projet.

## 13. Maintenance

Proposer séparément un forfait de maintenance légère si le client en a besoin.
