## Coûts externes

Le domaine et l'hébergement sont facturés séparément. Le client doit idéalement payer directement les abonnements récurrents ; le freelance peut ensuite effectuer la configuration.

## Paiement

- 50 % d'acompte avant production ;
- 50 % avant livraison finale / transfert des éléments finaux.

## Révisions

Deux séries de corrections sont incluses. Toute demande supplémentaire ou tout changement de périmètre doit faire l'objet d'une nouvelle estimation.

## Règle d'ajustement

Après les 5 premiers projets, mesurer :

- temps réel de production ;
- temps de communication ;
- coût des outils ;
- taux d'acceptation des devis ;
- nombre de corrections ;
- marge réelle.

Les prix doivent ensuite être ajustés à partir de ces données.
