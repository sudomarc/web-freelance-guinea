- React ;
- Next.js ;

- APIs ;

## Critère de passage

Ne pas passer au niveau suivant simplement parce qu'une technologie est intéressante. Passer lorsque le niveau actuel est suffisamment maîtrisé pour produire de manière fiable et rentable.
