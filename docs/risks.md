# Risques et garde-fous

| Risque | Garde-fou |
|---|---|
| Client ne paie pas | 50 % d'acompte avant production |
| Modifications infinies | 2 séries incluses |
| Projet trop complexe | qualification + refus explicite |
| Coûts récurrents | domaine / hébergement séparés |
| Support permanent | forfait de maintenance distinct |
| Prix trop faible | mesurer le temps réel et ajuster |
| Bug après livraison | contrôle qualité + période de correction définie |
| Perte de données | conserver une copie du projet |
| Contenu manquant | ne pas lancer la production finale sans éléments essentiels |
| Dépendance à un outil | conserver autant que possible une copie/export exploitable |
| Promesses excessives | ne vendre que les compétences maîtrisées |
| Conflit sur le périmètre | devis et brief écrits |

## Règle de décision

Si une demande dépasse le niveau technique maîtrisé, trois options seulement :

1. réduire le périmètre ;
2. apprendre avant de vendre si le délai le permet réellement ;
3. refuser / orienter vers un autre prestataire.
